## Pré-requisitos

- python 3.10 ou superior
- pip 
- mkdocs


## Executando

Para executar o projeto, depois de clonado crie o ambiente virtual:

```bash
python3 -m venv .venv
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Suba o servidor local:

```bash
mkdocs serve
```

Acesse no navegador:

```text
http://127.0.0.1:8000
```
